## The Reviewer did its job

> "When the differential path dies, immediately exercise the remaining applicable channel before concluding — run analyse kind=differential in its supported form and then an oracle-based chosen-plaintext differential … rather than resolving refuted from documentation with all 64 queries unused."

That is a correct diagnosis of a real shortcut. The Adversary opened a chosen-plaintext hypothesis, **tested a different attack** (`solve`), hit a schema error on the right one, then declared the hypothesis refuted by reading the documentation rather than running the corrected call. The construction's own text says a few thousand chosen pairs should work; the budget was never touched.

The review is now in `adversary.view()['reviews']`, so the next Adversary turn sees the flaw and the advice.

## Defects this run surfaced

1. **The tool schemas were undocumented.** The Adversary guessed `pairs: [[pt,ct],…]` for `analyse differential`; the tool takes `difference: hex, pairs: int`. It cost a turn, and the guess was reasonable — the charter said "differential costs two queries per pair" with no signature. Fixed by relaying the exact signatures; the charters should carry them.
2. **`flaw` was a label field but nothing said so clearly.** The Reviewer wrote `"no_fallback_after_refutation — once the differential…"` and the validator refused it. The label and the explanation belong in different fields; that needs saying in the charter.
3. **A refutation can be asserted instead of executed.** The Adversary resolved a hypothesis on documentation alone. The schema for `resolve` cannot tell a run from an argument — this is exactly the provenance problem one level up: it applies to *experiments*, not just breaches.

## What it establishes

The six-role loop closes, the Reviewer's queue fires on its own trigger, and the review reaches the Adversary's projection. The process finding is sharper than any of the previous runs: the agent's failure was not a wrong belief, it was **not testing the belief it had written down**.
